# Reflection: jakobrunge_tigramite

Tigramite is irregular. It has bursts in 2017, 2022 and 2023 that line up with releases and slower months in between. There are 2 gaps of 3+ months and the longest is 2025-02 to 2025-05 (4 months).

Both gaps start right after a release. Before the longest one, the main commit was a new feature that went out in version 5.2.7.0 in December 2024. Some of the other commits WoC has before the gap are from PR branches, which made it a bit confusing. The maintainer was still answering issues during the gap, so I think it was just a break after the release.

The first commit after the gap was from a new contributor, Vincent Verjans, but the real restart was Jakob Runge making bug fixes and releasing 5.2.8.0 in July 2025. It is Active and recent commits are bug fixes and features.
