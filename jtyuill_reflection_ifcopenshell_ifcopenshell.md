# Reflection: ifcopenshell_ifcopenshell

IfcOpenShell has a rising pattern. It had fewer than 40 commits a month from 2011 to 2014 and then grew a lot, especially after 2020, with a peak of 785 commits in 2023-08. There is only one gap of 3 or more months, 2014-08 to 2014-10, so that is also the longest.

This gap was hard to interpret. The commits before and after it are normal bug fixes and features, and none of them mention a pause. The repo only moved to GitHub in 2015, so there are no issues or PRs from that time. Most of the commits before the gap were by Thomas Krijnen, so my guess is he was just busy for a few months.

Krijnen also ended the gap in November 2014, so the same person brought it back. Later growth came from new contributors like Dion Moult. The project is Active and recent commits are mostly build and release work.
