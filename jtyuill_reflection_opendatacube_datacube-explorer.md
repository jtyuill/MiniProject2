# Reflection: opendatacube_datacube-explorer

datacube-explorer is irregular. It has large bursts (2016, 2018, 2020, 2022 and 2025) with quiet months between them. There are 3 gaps of 3+ months, and two of them are 5 months long, so I used the earlier one, 2017-05 to 2017-09.

Before the gap almost every commit was by Jeremy Hooke, adding UI features and setup docs. Nobody else was committing, so the project depended on one person, and my guess is his attention moved somewhere else for a while.

The gap ended when Alex Vincent from Geoscience Australia opened an issue about running the dashboard, fixed it himself, and sent a few more PRs. Hooke came back in November 2017 with a lot of commits, so it was a mix of a new person and the original maintainer. The project is Active and recent commits are mostly dependabot and pre-commit bot updates.
