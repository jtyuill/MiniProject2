# Reflection: choderalab_pymbar

pymbar is irregular. It has short bursts of commits (2013, 2015, 2018, 2020 and 2022) around sprints and releases, with long slow stretches in between. There are 6 gaps of 3+ months and the longest is 2018-04 to 2018-12 (9 months).

This one was pretty easy to interpret. Before the gap there was a cleanup sprint and some bootstrap work, and the last bootstrap commit is literally called "Boostrap pause." The maintainers still answered issues during the gap but didn't change any code, so it seems like they paused while deciding what to do next.

Michael Shirts restarted it in January 2019 by fixing the README examples and then adding a pmf.py module. He was active before the gap too, so it was the same person. New contributors helped later in 2020 and 2022. It is Active and recent commits are mostly bug fixes and features.
