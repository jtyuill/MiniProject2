# Reflection: kvos_coastsat

CoastSat is irregular. There is a spike in 2018-12 and then bursts every so often, with no real trend. It has 3 gaps of 3+ months and the longest is 2025-06 to 2025-09 (4 months).

The commit messages don't say why it stopped. Before the gap the commits were setup docs and some bug fixes. On GitHub, Kilian Vos (the only real maintainer) was still answering issues over the summer, so it wasn't abandoned. There was an open Earth Engine authentication bug (#596) that he said was painful to fix, so I think he just didn't have time.

It recovered in October 2025 when he fixed the authentication problem and updated the README, so it was the same person. A couple of other names show up in WoC after the gap but those are fork commits. It is Active and recent commits are mostly documentation and some new features.
