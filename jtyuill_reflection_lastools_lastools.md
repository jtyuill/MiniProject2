# Reflection: lastools_lastools

LAStools looks U-shaped. It was very busy from 2014 to 2019, mostly from the founder Martin Isenburg, then dropped a lot from 2020 to 2023 and picked back up in 2024. It has 2 gaps of 3+ months and the longest one is 2023-03 to 2023-06 (4 months).

The gap was easy to find but the commit messages don't explain it. Martin Isenburg died in 2021, so a smaller team at rapidlasso was left maintaining it. Some issues opened during the gap never got answered, so I think the team just didn't have much time.

It recovered when Jean-Romain added a COPC reader/writer and Jochen Keil went back to fixing bugs. Both had committed before the gap. In 2024 rapidlasso started pushing more of its work to GitHub and new contributors joined. It is Active, and recent commits are mostly release bumps and README changes.
