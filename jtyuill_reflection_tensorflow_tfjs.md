# Reflection: tensorflow_tfjs

TensorFlow.js grew fast after it started in 2017 and peaked in 2019-2020 at almost 1000 commits a month. After that it declined, and since 2024 most months only have a handful of commits, a lot of them from dependabot. I classified it as declining.

There are no gaps of 3 or more months. The longest zero run is just one month, 2025-10. The commits before and after it are mostly dependabot dependency bumps, so the themes are Automated bot contributions and Dependency updates.

Since there isn't a real gap, recovery doesn't really apply. The decline is probably because Google put fewer people on it, since the top contributors in 2020 were Google engineers. The last GitHub commit is 2026-04-06 so it is Active, and recent commits are mostly maintenance and bug fixes.
