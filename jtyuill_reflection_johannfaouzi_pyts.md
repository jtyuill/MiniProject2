# Reflection: johannfaouzi_pyts

pyts is declining. It was busiest in 2018-2020 around its main releases, and after 2020 it never had more than 27 commits in a month. There are 6 gaps of 3+ months and the longest is 2023-10 to 2024-10 (13 months).

Before the gap the commits were about the v0.13.0 release and updating dependencies. This gap was hard to interpret because WoC counts commits from PRs that were never merged, so the gap "ends" with a PR that was never accepted. The maintainer answered a few issues but later ones got no reply, so I think he just didn't have much time.

Activity came back with a few PRs from outside contributors, and then Johann Faouzi, the original maintainer, fixed the docs and some deprecation errors in June 2025. The last commit is 2025-06-18, so it is Active under the README rule.
